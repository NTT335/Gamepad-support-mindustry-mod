# Mindustry Gamepad Support Mod

Кроссплатформенный Java-мод для **Mindustry v154+ (Java 17)**, добавляющий полноценную поддержку геймпадов и контроллеров (DualSense, DualShock 4, Xbox One/Series, Switch Pro, стандартные HID/XInput/DirectInput устройства).

---

## 🎮 Основные возможности

### 1. Три режима управления
- **Normal (L2)**: 
  - Исследование карты и свободная камера: перемещение камеры крестовиной (D-Pad) с плавным и комфортным управлением. Камера отвязывается от игрока и позволяет свободно летать по всей карте (например, следить за базой противника) без принудительного стягивания назад.
  - Быстрый возврат камеры к игроку нажатием **L2**.
  - Плавный зум камеры на **L3 (клик левого стика - приближение)** и **R3 (клик правого стика - отдаление)** без рывков и смещения прицела.
  - Управление юнитом левым стиком, стрельба правым триггером (R2), добыча ресурсов, захват дружественных турелей/заводов/юнитов, взаимодействие с блоками и сброс предметов.
- **Build (R1)**: 
  - Выбор категорий и блоков крестовиной (D-Pad), быстрое строительство одиночных блоков и линий, пакетный снос (deconstruction), пипетка (копирование блока под курсором), копирование и вставка схем (schematics) из буфера обмена с поворотом на 90°.
  - **Восстановление и ремонт заброшенных построек (R2 при пустом курсоре)**: если в режиме строительства курсор очищен (нажата кнопка X / `cancelAll` и не выбран блок), нажатие или выделение области зажатым **R2** автоматически чинит и захватывает любые заброшенные постройки (`Team.derelict`), а также восстанавливает разрушенные постройки вашей команды из очереди планов. При этом область подсвечивается зеленым цветом (`Pal.heal`) с отображением количества поставленных в очередь работ.
- **Command (L1)**: Полноценное RTS-управление войсками: выделение одиночных юнитов и рамочное выделение области, отдача приказов атаки/перемещения, точка сбора (rally point) для фабрик, навигация по кнопкам командной панели D-Pad'ом.

### 2. Навигация по интерфейсу и виртуальный курсор
- Свободное перемещение стиком с настройкой мертвых зон (deadzone), чувствительности и сглаживания.
- Клик, удержание и перетаскивание ползунков (drag & drop).
- Скроллинг списков правым стиком.
- **Умный поиск в меню и кампании (Дерево технологий, карты планет, списки схем)**:
  - По умолчанию текстовые поля не перехватывают кнопки геймпада: кнопка **X (Cross)** и триггер **R2** выполняют стандартный клик мыши по элементу под курсором (сектор, исследование, схема, кнопка) — символ "X" больше не спамится в поле поиска.
  - Нажатие **△ (Треугольник / Y)** включает режим ввода в поиск геймпадом (символы D-Pad и геометрические значки).
  - Нажатие **Share / Скриншот (Back / View)** выключает режим ввода поиска и возвращает обычный курсор.
- Управление тактической паузой, открытие меню паузы и работа с полноэкранной миникартой (зум и панорамирование).

### 3. Встроенное меню настроек
- В меню игры (*Settings -> Controls*) добавляется раздел **"Controller"**.
- Переназначение любой кнопки под индивидуальные предпочтения с таймером ожидания нажатия.
- **Раздельная инверсия осей стиков (OX и OY) в каждой из 6 категорий**:
  - В каждой из 6 вкладок (*1. General, 2. Normal, 3. Build, 4. Command, 5. Menu, 6. Minimap*) доступны 4 независимых переключателя:
    - Инвертировать Left Stick X (OX)
    - Инвертировать Left Stick Y (OY)
    - Инвертировать Right Stick X (OX)
    - Инвертировать Right Stick Y (OY)
  - Можно инвертировать оси как глобально (во вкладке General), так и индивидуально переопределять поведение для каждого конкретного режима.
- Регулировка скорости курсора, скорости камеры (D-Pad), масштабирования (зума), мертвых зон и времени зажатия.
- Кнопки сброса настроек для выбранной вкладки (*Reset tab*) и для всех параметров сразу (*Reset all*).

## 🕹️ Схема управления по умолчанию (PlayStation / Xbox)

| Действие | PlayStation | Xbox |
|---|---|---|
| **Перемещение юнита** | Левый стик (L-Stick) | Левый стик (L-Stick) |
| **Управление курсором** | Правый стик (R-Stick) | Правый стик (R-Stick) |
| **Свободный полет камеры** | D-Pad (крестовина) | D-Pad (крестовина) |
| **Центрировать камеру на игроке** | L2 | LT |
| **Режим: Normal** | L2 | LT |
| **Режим: Build** | R1 | RB |
| **Режим: Command** | L1 | LB |
| **Огонь / Подтвердить постройку** | R2 | RT |
| **Взаимодействие / Выбор / Огонь** | X (Cross) | A |
| **Отмена / Снос / Назад** | ○ (Circle) | B |
| **Выбор категории / Включить поиск в меню** | △ (Triangle) | Y |
| **Выбор блока / Поворот** | □ (Square) | X |
| **Пауза игры / Выключить поиск в меню** | Share / Select | Back / View |
| **Меню паузы / Выход** | Options / Start | Menu / Start |
| **Зум камеры (In / Out, плавно)** | L3 / R3 | L3 / R3 |
| **Миникарта** | L3 + R3 | L3 + R3 |

## 💻 Платформенная совместимость

Мод спроектирован с модульной архитектурой провайдеров (`CompositeProvider`), что обеспечивает работу без сторонних нативных библиотек:

1. **Windows 10 / Windows 11**:
   - Работает через `GlfwProvider` (динамическая рефлексия к GLFW внутри десктопного рантайма игры).
   - Поддерживает DirectInput и XInput контроллеры без дополнительных драйверов.

2. **Linux (X11 / Wayland)**:
   - Основной режим через `GlfwProvider`.
   - Встроен резервный zero-dependency драйвер `LinuxJsProvider`, читающий напрямую события `/dev/input/js*`. Работает даже при специфических настройках оконного менеджера.

3. **macOS (Apple Silicon & Intel)**:
   - Работает через `GlfwProvider` (интеграция с GameController framework и IOKit через GLFW).

4. **Android (включая старые версии Android)**:
   - Работает через `AndroidProvider`.
   - Использует рефлексивное сканирование `android.view.InputDevice` и подсистему событий ввода Arc Engine. Поддерживает Bluetooth и OTG-геймпады.

5. **iOS**:
   - На платформе iOS запуск сторонних Java/JAR модов ограничен политикой безопасности операционной системы Apple (запрет JIT/динамической загрузки исполняемого Java-байткода и изоляция песочницы).

## 🛠️ Сборка проекта

Требования:
- **JDK 17** или новее.
- Gradle (включен или системный).

```bash
# Сборка JAR-мода:
gradle jar

# Собранный файл появится в:
# build/libs/GamepadSupport.jar
```

Для установки скопируйте `GamepadSupport.jar` в папку модов Mindustry:
- **Linux**: `~/.local/share/Mindustry/mods/`
- **Windows**: `%AppData%/Mindustry/mods/`
- **macOS**: `~/Library/Application Support/Mindustry/mods/`
- **Android**: через меню игры *Mods -> Import mod -> Open file*.
